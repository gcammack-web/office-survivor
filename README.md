# simple-game

Two small browser/desktop game projects:

## Office Survivor (Godot 4)

**Office worker survivor** — staplers, coffee, passive-aggressive emails as upgrades.

A Vampire Survivors–style roguelite built for Steam. See [office-survivor/README.md](office-survivor/README.md) for how to run.

```bash
# Open in Godot 4.3+ and press F5, or:
/Applications/Godot.app/Contents/MacOS/Godot --path office-survivor
```

## Simple Quest (HTML5)

A short top-down RPG in the repo root. See controls below.

```bash
python3 -m http.server 8080
# Open http://localhost:8080
```

### Simple Quest controls

| Key | Action |
|-----|--------|
| WASD / Arrows | Move |
| J | Attack |
| Space | Talk to NPC |
| I | Inventory |
| E | Use item |
| Q | Quick potion |
| Tab | Next item |
